### Laptop and mobile QA access

The current loopback service is healthy at `http://localhost:3011/#/`. A direct `localhost` link on an iPhone fails because it points to the iPhone, not the Mac. The immediate zero-cost route is ChatGPT Remote connected to this exact Mac while `npm run qa:remote` keeps the managed preview and temporary keep-awake guard running. This proves host-browser review, not native iPhone Safari.

Tailscale was recommended for security and simplicity, not price: its private Serve path can proxy a loopback service without rebinding the prototype to every local interface. The current zero-cost order is:

1. ChatGPT Remote now, with no new vendor or network exposure.
2. An authenticated Microsoft Dev Tunnel pilot only if native on-the-go Safari is required; Microsoft publishes a free 5 GB monthly transfer quota, but the service is preview and has no SLA.
3. NetBird Cloud Free as a private-mesh alternative; its free plan publishes up to 5 users and 100 machines, but the prototype would need a narrowly scoped interface proxy.
4. Tailscale Standard only if the simpler private path justifies the published $8 per active user monthly price.

Cloudflare Quick Tunnel is not acceptable for this private requirement because it creates a random public URL without the required private access boundary. No tunnel, mesh client, public endpoint, paid plan, or vendor terms were activated. The complete decision and operating steps are in the [mobile access packet](../reviews/my-way-ahead-private-mobile-access-packet-2026-07-21.md) and [QA runbook](../../../../prototypes/worthward-mobile/QA_ACCESS.md).

## Brand decision

The name carries the intended double meaning: show a credible way forward while helping the user build durable career advantage. It works emotionally. It does **not** clear the strategic or legal bar for a master-brand lock.

The [name knockout screen](../reviews/way-ahead-name-knockout-screen-2026-07-21.md) found high collision and branded-search risk: `wayahead.com` is registered, an exact live federal `WAY AHEAD` application exists in Class 41, exact-name SaaS use exists, and career or employability associations already use the phrase. Some modifier domains returned no Verisign registration object, but that does not prove availability, price, or clearance.

CEO recommendation: use Way Ahead only as the current private checkpoint label, preserve `Your way ahead` as possible emotional territory, and queue a short distinctive-name sprint inside Private-Alpha Readiness. Do not spend engineering effort on a full rename, buy a domain, file a mark, or launch publicly. `My Way Ahead` remains the comparison control, not a cleared fallback. Legacy `my-way-ahead` paths and the isolated ClickUp folder remain stable identifiers until a separately reviewed migration prevents broken provenance.
