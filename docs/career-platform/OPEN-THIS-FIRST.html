Working product

The smallest trustworthy career-decision loop is interactive

The responsive prototype now connects Career Baseline, Opportunity Radar, Radar Brief, a seven-job collection, one-job Review, proof correction, user decisions, Pursuits, and an exact synthetic approval path. It performs no live model calls, uploads, job-board actions, messages, or submissions.

Run or inspect the prototype

The code includes light, dark, and device themes; realistic ambiguity fixtures; loading, partial, capacity, error, conflict, no-action, and offline states; local persistence; and an approval state machine that never treats a click as a submission.

Selected experience

A connected decision journey, not one overloaded screen

The three concepts are not competing versions of one screen. Radar Setup defines the alert. A dated Radar Brief shows results. Selecting a job opens Opportunity Review. Choosing Pursue starts a native Pursuit, while external approval remains separate.

Concept warning: the screenshots contain stale demonstration values and duplicated actions. The governed truth is Going `85/100`, compensation starting at `$175,000 plus equity` with no public upper bound, and `Investigate` until proof is validated. The user decision appears once as Pursue, Watch, or Pass. Fixed review-time promises must be removed.

Theme behavior

Settings must offer System, Light, and Dark. System is the default. Both themes keep the same hierarchy, proof states, interaction states, accessibility, and content.
