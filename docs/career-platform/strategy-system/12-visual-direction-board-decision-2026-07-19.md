# 12 Visual Direction Board Decision

Date: 2026-07-19
Decision owner: Matt Dimock, Board
Status: approved for local synthetic prototype implementation

## Decision

Use the **My Way Ahead Executive Evidence** direction as the governing visual system.

The selected reference is:

- [`selected-executive-evidence-timeline.png`](../../../output/visuals/my-way-ahead/selected-executive-evidence-timeline.png)

This selection combines the dark Executive Evidence composition from Option 2 with the original connected four-step timeline beneath `What we’ll check`.

## Implementation authority

This decision authorizes local, reversible implementation and QA with synthetic fixtures and no paid services. It does not authorize public or private hosting, production customer data, paid APIs, billing activation, external tester recruitment, a public brand lock, domain purchase, or trademark/legal spend.

## Required interpretation

- Preserve the clear editorial hierarchy, near-black mineral canvas, restrained mint action color, serif display type, sans-serif interface type, and connected four-step Integrity Preview timeline.
- Keep all timeline nodes neutral before a role is submitted. A completed or active state may appear only after the corresponding check actually runs.
- Build System, Light, and Dark modes with identical meaning and controls. Light mode is a designed warm-neutral counterpart, not a mechanical inversion.
- Use a standard icon library for interface icons. Do not introduce a compass, road, path, arrow, gradient, glow, or decorative timeline motif.
- Do not copy unsupported claims from the mock. The implementation must not imply a source, employer, liveness state, score, result, or completed check before evidence exists.
- Keep My Way Ahead and `mywayahead.com` provisional until the separate brand gate passes.

## Next gate

The next Board gate is a QA-passed private hosted checkpoint of the selected mobile-first funnel. Until then, implementation remains local and synthetic.
